# 一週間計画
こういうのはダラダラとやってしまうことが多いので、何か目標を決めて一週間でやってみるのが良いと判断したため、これを用意する。

## セクション１
GUIに興味があるならば、それを主題としてみるのが良いと思う。
- GUIで"Hello, World"を表示する: 1
- 簡易なアニメーションを表示する: 2

## 技術選定
Scenicを使うことに決定する。理由は依存関係の少なさと、似たようなライブラリを自作する際に参考になりやすいと判断したためである。
もっとも、自作するかは未定だが。

## 現状
sampleを用意して動くことは確認したので、tinyディレクトリにそれを移行していく。
まずは公式ドキュメントを見て、Configを用意してみる。Configはどうやら標準ライブラリのようであり
いわゆるapplicationファイルやyamlの設定ファイルに該当するようなので、寄り道になるがこれについてざっくり見る。

## Tips
- ScenicはElixir/ErlangとOpenGLのみを依存関係としている
- ローカルPC上のウィンドウにアプリケーションを表示する処理はscenic_driver_localドライバーが行う。このドライバーはGLFWとGLFWライブラリをつかってOpenGLに接続する
- scenic.runのタスクの定義を発見した。やっていることはmix run --no-haltである。特殊なことは何もしていない
- ConfigはElixirの標準ライブラリ。Elixirで書ける設定ファイルを作成できる
